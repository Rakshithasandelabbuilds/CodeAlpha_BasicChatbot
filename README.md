#Basic Chatbot
This is a simple rule-based chatbot built using Python as part of the CodeAlpha Python Programming Internship.

The chatbot responds to basic messages such as greetings, questions about its name, and thanks. It also supports simple conversations and allows the user to exit by typing "bye".

## Technologies Used
- Python

## How to Run
1. Make sure Python is installed.
2. Open the terminal in the project folder.
3. Run `python statbot.py`.

## Features
- Simple text-based conversation
- Predefined responses
- Handles different inputs
- Option to exit the chat
